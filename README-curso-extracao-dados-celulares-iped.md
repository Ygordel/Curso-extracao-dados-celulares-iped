# Curso de Extração e Análise de Dados de Celulares com IPED

Curso prático de perícia digital aplicada a dispositivos móveis, utilizando o IPED para preparação, processamento, indexação e análise de evidências digitais. Aborda mensagens, contatos, chamadas, imagens, vídeos, documentos, localização, navegação, pesquisa de dados e elaboração de relatórios técnicos.

## Objetivos

- Compreender os fundamentos da perícia digital.
- Conhecer os princípios de preservação e cadeia de custódia.
- Preparar evidências digitais para análise.
- Utilizar o IPED para processamento e indexação.
- Pesquisar e analisar artefatos de dispositivos móveis.
- Organizar achados e produzir relatórios técnicos.

## Estrutura

O curso está dividido em módulos progressivos, desde os fundamentos até casos práticos e exercícios.

## Uso responsável

Utilize somente dados e evidências para os quais exista autorização legítima de análise. O material possui finalidade educacional.

## IPED

O IPED (Indexador e Processador de Evidências Digitais) é um projeto de código aberto voltado ao processamento e à análise de evidências digitais.
