# Curso-extracao-dados-celulares-iped
Curso prático de perícia digital aplicada a dispositivos móveis, utilizando o IPED para preparação, processamento, indexação e análise de evidências digitais. Aborda mensagens, contatos, chamadas, imagens, vídeos, documentos, localização, navegação, pesquisa de dados e elaboração de relatórios técnicos.
